# R3.1d — Lattice Estimator Validation

## Objective

Validate the underlying RLWE hardness of the exact bounded-base
`research-4096` configuration characterized in R3.1c.

## Methodology

The analysis uses the same methodology retained from R2.9:

- Lattice Estimator revision:
  `8f1ff7e20a4d3391e3badff1d76825314db225bc`
- reduction cost model: `RC.MATZOV`
- ring/LWE dimension: `n = 4096`
- secret distribution: uniform ternary
- error distribution: discrete Gaussian
- Gaussian sigma: `3.19`
- conservative estimator sample model: `m = oo`

The number of exposed RLWE evaluation-key ciphertexts is recorded from
R3.1c, but is not mapped directly to the estimator's scalar-LWE `m`
parameter.

## Gate

The 128-bit classical-security estimator target is evaluated against the
minimum estimated work factor over the tested attacks and active levels.

    TARGET_BITS=128
    BINDING_LEVEL=0
    BINDING_ATTACK=primal_bdd
    BINDING_ESTIMATE_BITS=130.3
    SECURITY_MARGIN_BITS=2.3
    R3_1D_ESTIMATOR_GATE=PASS

## Scope of claim

This estimator gate characterizes the hardness of the underlying
uniform-ternary-secret RLWE parameterization under the documented
Lattice Estimator methodology and MATZOV reduction-cost model.

It does not independently prove circular/KDM security for evaluation
keys encrypting secret-dependent values such as `B^j * s^2`.

The bounded-base evaluation-key construction is supported separately by
the R3.1b correctness and noise-validation evidence.

## Conclusion

The exact `research-4096` top-level modulus used by the bounded-base
implementation clears the targeted 128-bit classical Lattice Estimator
gate.

Level 0 is the binding security level.
